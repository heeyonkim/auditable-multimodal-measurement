# Measure-specification prototype

[Home](../../README.md) / [Documentation](../../docs/README.md) / Measurement prototype

Use this prototype to define a measure before analyzing recordings. Choose an example or write your own construct, select the evidence to use, record alternative explanations and validation tests, and export your specification as JSON. The prototype does not process recordings or calculate new measurements.

The interface currently includes four worked examples from the completed pilots:

- conversational space;
- personal-baseline behavioral deviation;
- editorial responsiveness; and
- delivery-text divergence.

Every recipe distinguishes direct observations, derived measures, contextual evidence, and prohibited interpretations. The interface does not ask AI to assign an opaque psychological label.

## Try it in your browser

[Try defining a measure](https://auditable-measurement-prototype.cornell-rese-2689.chatgpt.site). No download or sign-in is required. This public demonstration uses the same page as the repository. Your measurement entries stay in your browser, and you can download the specification as JSON.

## Run locally

Download the repository using GitHub’s **Code → Download ZIP** button, extract it, then open [index.html](index.html) in a modern browser. The HTML file is a local interactive tool; GitHub’s file preview shows its source rather than running it. The tool has no external dependencies and sends no data to a server.

## Research status

This is a Stage 1 prototype. The included recipes are exploratory specifications, not validated construct measures. Stage 2 would add saved recipe comparison, dataset-specific field mapping, validation evidence, version history, and export adapters for statistical software.
